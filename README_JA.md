# MD-Memo

思考の流速を阻害しない、極限の軽量性を追求したネイティブMarkdownスクラッチパッド。
Go言語とOS標準のWebエンジンにより構築。起動遅延ゼロ、メモリ消費の最小化、そして完全なデータ主権を提供します。

## 概要

文章を書くための道具は、これまで「軽快さ」か「多機能さ」の二者択一を迫られてきました。

現代的なナレッジベースは構造化に優れる一方で、重厚なランタイムによって起動遅延とメモリ圧迫を生み、思考の初速を減衰させます。一方で古典的なテキストエディタは即座に起動しますが、現代の技術執筆に必要な知性——リアルタイム補完、入力の自動正規化、構文の視覚化——を欠いています。

MD-Memoはこの境界を再構築します。コンパイルされたシステム性能とノイズのない筆記面を統合し、知識を管理する重厚な保管庫ではなく、「脳とディスクの間を直結する無色透明な器」として動作します。

## 設計の柱

### 1. ゼロレイテンシ・ネイティブエンジン
Goによる約3.5MBの超軽量ランタイムとOS標準のWebViewを直結し、重厚なNode.js/Chromiumの多重レイヤーを完全に排除しました。
- **瞬時の復帰**: タスクトレイからわずか 10ミリ秒（0.01秒） でウィンドウが復帰し、カーソルが即座に点滅。
- **Windows COM統合**: PowerShellの重いスクリプト呼び出しを排し、Windows COM `IFileDialog` を直接呼び出すことで、ミリ秒台の高速ファイルダイアログを実現。
- **自動メモリ回収**: 待機時や最小化時はメモリ回収機構が稼働し、フットプリントを 5〜15MB まで自動圧縮。常時常駐させてもOSのリソースを圧迫しません。

### 2. 4層 Auto-IME Guardian
日本語とプログラミング言語が混在する技術執筆において、入力モード切替の認知摩擦を根本から解消します。
- **無意識のスクリプト反転**: 半角英数モードのままローマ字を打ち始めても、音韻構造を検知して3文字以内に自然な日本語入力へと移行。
- **構文領域の完全隔離**: コードブロック（```）、インラインコード（...）、URL内では判定が0nsでバイパスされ、`interface`、`component`、`const` などの識別子が誤変換されることは構造上あり得ません。
- **AIタイポ修正 (Alt+C)**: 打ち間違いや変換ミスをショートカット一発でスマートに修正。
- **マイクロ秒単位の実行**: 計算言語学に基づく音韻対数尤度比検定（LLRT）を採用。1打鍵あたり約11マイクロ秒、静的フットプリント約35KBで動作し、タイピング遅延は物理的にゼロです。

### 3. 静寂の知性と感覚的集中
知性は画面を埋めるチャットボットではなく、必要な瞬間にだけ指先に寄り添う影のように振る舞います。
- **オフライン・ゴーストテキスト**: 予測補完が薄いグレー文字でインライン表示。Tab で全文受け入れ、Ctrl+→（macOSは Option+→）で1単語ずつ段階的受け入れ。Ollama、LM Studio、vLLM とローカル接続し、通信費ゼロ・完全プライベートで動作。
- **Cursor Aura (Ambient Affordance)**: タイピングを止めた瞬間、キャレット周辺が穏やかに発光し、認知のフローを乱すことなく視線と思考を執筆中の行へと優しく引き戻します。
- **推論ブロックの自動除去**: DeepSeek-R1等の <think> タグはリアルタイムに自動除去され、純粋な思考結果のみが画面に紡がれます。

### 4. マルチモーダルな構造抽出
- **画像貼り付けによる即時テーブル化 (Ctrl+V)**: クリップボード内の表画像やスクリーンショットをペーストするだけで、Gemini Visionが構造を解釈し、整然としたMarkdownテーブルへ自動変換。
- **Mermaid 11 図解生成**: 粗い箇条書きメモからフローチャート、シーケンス図、タイムラインを即座に生成。Gemini Imageモデルを介したベクター画像への直接出力もサポート。
- **ローカル画像の高速配信**: 内部エンドポイント（/api/image）によるストリーミング処理で、ローカル画像を含む長文ドキュメントも同期スクロール付きで滑らかにプレビュー可能。

## インストール

インストーラー不要の単一バイナリ、またはパッケージマネージャーから導入できます。

### Windows
```powershell
winget install youshinh.md-memo
```

### macOS
```bash
brew install --cask youshinh/tap/md-memo
```

単一実行ファイル形式のアーカイブ（.zip / .app）は [GitHub Releases](https://github.com/youshinh/md-memo/releases) から直接入手可能です。

## システム構成

```
[ フロントエンド: 等幅Textarea / Ghost Overlay / Cursor Aura / Markdown AST ]
                                       ▲
                                       │ 双方向RPCブリッジ (Wails v2)
                                       ▼
[ コアエンジン: Go 1.26 (~3.5 MB) / OSネイティブWebView / Windows COM IFileDialog ]
       │                                                      │
       ├─► ローカルファイルIO (UTF-8 / Shift_JIS)            ├─► ローカルオフラインLLM (Ollama / LM Studio)
       ├─► ループバック画像エンジン (/api/image)             └─► クラウド推論エンジン (Gemini / Claude / OpenAI)
       └─► アイドルメモリ回収 (5〜15 MB)
```

## 設計思想

1. **道具は透明でなければならない**: ソフトウェアはそれ自身の存在を誇示してはなりません。装飾、不要なアニメーション、思考を遮る通知を完全に排除し、画面には文字のみが存在する状態を保ちます。
2. **決定論的なデータ主権**: 記述された思考は、常にローカルディスク上のクリーンなUTF-8プレーンテキストとして保持されます。独自DBによる囲い込みや、基幹機能におけるクラウド依存を許容しません。
3. **速さとは敬意である**: 思考を書き留めるために書き手を3秒待たせる道具は、人間の精神に対する敬意を欠いています。MD-Memoのすべてのアーキテクチャの決定は、思考の流速を守るために下されています。
