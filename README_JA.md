# MD-Memo

> 一瞬の思考を逃さず捉えるために設計された、ゼロレイテンシ・ローカルファーストのMarkdownスクラッチパッド。

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Go Version](https://img.shields.io/github/go-mod/go-version/youshinh/md-memo)](https://golang.org/)
[![Platform](https://img.shields.io/badge/platform-win%20%7C%20mac%20%7C%20linux-lightgrey)](#クイックスタート)

**MD-Memo** は、システムトレイに静かに常駐する高帯域幅のキャプチャツールです。コンパイルされた Go コアと OS ネイティブの WebView で構築され、数ミリ秒で復帰し、多言語 IME の入力状態を自律的に制御し、作業が終われば直ちに視界から消えます。

## メモ帳のパラドックス (The Scratchpad Paradox)

Obsidian や Notion に代表される現代のナレッジベースは、長期的な情報蓄積・構造化には非常に優れています。しかしそのアーキテクチャ上、起動レイテンシや重いメモリフットプリントが避けられません。ふとした閃きを書き留めたいときや、一時的なエラーログを流し込みたいときに、数秒の Electron 初期化を待たされることは思考の勢いを削ぎます。

**MD-Memo は、保管庫（Vault）の代替ではありません。その手前に置く「摩擦ゼロのバッファ」です。**

| 項目 | 一般的なテキストエディタ | ナレッジ保管庫 (Vault) | MD-Memo |
|---|---|---|---|
| **アーキテクチャ** | C++ / Swift | Electron / JVM | **Go 1.26 + OS ネイティブ WebView** |
| **復帰レイテンシ** | ~100ms (コールド起動) | 2.0s – 5.0s | **< 15ms (システムトレイ常駐時)** |
| **待機メモリ** | ~15 MB | 400 MB – 800 MB+ | **5 – 15 MB (積極的 GC)** |
| **データ保存** | プレーンテキスト | 独自DB / プロプライエタリ | **100% ローカル POSIX プレーンテキスト** |
| **ファイルダイアログ** | OS ネイティブ | Node.js IPC ラッパー | **COM `IFileDialog` / Cocoa ネイティブ** |

> **運用のヒント**: MD-Memo の保存先を作業中の Obsidian Vault、Git リポジトリ、またはデイリーログ用フォルダに直接向けることで、即時入力ターミナルとして活用できます。

## アーキテクチャと機能

### 1. 最小限のフットプリントとミリ秒未満の復帰
システムに負荷をかけることなく 24 時間 365 日稼働するよう設計されています。
- **瞬時の呼び出し (`Ctrl+Alt+M` / `Option+Cmd+M`)**: 重いレンダリングパイプラインを迂回し、システムトレイからカーソル位置とバッファを維持したまま瞬時に復帰します。
- **積極的なアイドルメモリ回収**: ウィンドウ最小化時やアイドル時に `debug.FreeOSMemory()` を実行し、アクティブワーキングセットを 5〜15 MB に自動圧縮します。
- **OS ネイティブダイアログ**: Windows COM および macOS Cocoa パネルとの直接連携により、ファイル操作をネイティブかつ瞬時に実行します。

### 2. 自律型 IME シールド
CJK（日本語・中国語・韓国語）環境での技術執筆における入力モード切り替えの摩擦を、アルゴリズムによって解消します。
- **構文領域の保護**: インラインコード（`` `...` ``）、コードブロック、URL の内部では、全角文字の入力をインターセプトし、ごくわずかなオーバーヘッド（1打鍵あたり約 11 µs）で半角英数入力を強制します。
- **音韻自動修正**: 半角直接入力モードで入力されたローマ字の拍動を検出し、自動で日本語入力へ補正・変換します。
- **LLRT 駆動**: 対数尤度比検定（Log-Likelihood Ratio Testing）に基づく計算言語学処理により、入力速度を一切損ないません。

### 3. ローカルファースト AI 統合
AI は気が散るチャットウィンドウではなく、邪魔にならない静かな影として振る舞います。
- **完全オフライン予測補完 (Ghost Text)**: ローカルの Ollama、LM Studio、または vLLM を利用したオフライン予測補完を提供します。
- **推論ストリームの自動クリーンアップ**: DeepSeek 等の推論モデルが出力する `<think>` タグなどの思考トークンを、キャンバスに描画される前に自動除去します。
- **ワンクリックでのローカルセットアップ**: 設定画面から Gemma 4 E2B などの軽量モデルを直接取得・設定できるネイティブ統合を備えています。

### 4. UNIX パイプライン & CLI 自動化
メモを標準出力ストリームのように扱えます。
- **CLI 標準入力 (`cat log | md-memo`)**: ローカル TCP IPC 経由でターミナル出力を起動中の MD-Memo インスタンスへ直接パイプします。瞬時に転送されるほか、未起動時は自動起動します。
- **エディタ内 CLI エージェント (`Ctrl+Shift+E`)**: OS 操作を自然言語で記述（例: *「今日変更されたファイルを検索」*）。エージェントがシェルコマンドを生成し、組み込みの AST/正規表現安全エンジンで検証（`rm -rf /` などの破壊的コマンドをブロック）した上で、バックグラウンドの goroutine で実行します。
- **外部 CLI フィルタ (`Ctrl+Shift+B`)**: 選択したテキストを外部ユーティリティ（`jq`、`sort`、`prettier` など）に通し、バッファを瞬時に置換します。

### 5. 高速並列スクラップ検索
- **ゼロアロケーション並列スキャン**: `runtime.NumCPU()` のワーカースレッドと `bufio.Scanner` を活用し、デイリースクラップ（`scraps/YYYY-MM-DD.md`）全体に対してインメモリ並列 grep マッチングを実行します。
- **デバウンス付きインクリメンタル検索**: 150ms のデバウンスで快適な入力を維持しつつ、クリック一発で該当行へスクロールし、ハイライト表示します。

### 6. バックグラウンド Git 同期
プレーンテキストデータの耐久性を保ち、複数マシン間で同期します。
- **サイレント同期**: 起動時に自動で `git pull --rebase` を実行し、編集停止から 30 秒のアイドル後に `git add/commit/push` を自動実行します。
- **コンフリクトフリー設計**: 設定画面で空の GitHub/GitLab リポジトリ URL を指定するだけで、安全な自動クラウドバックアップを確立できます。

## システムトポロジー

```text
[ フロントエンド: 等幅キャンバス / Ghost Overlay / スクラップ検索UI ]
                               ▲
                               │ 双方向RPCブリッジ (Wails)
                               ▼
[ コアエンジン: Go 1.26 / OSネイティブWebView / ネイティブダイアログ ]
       │
       ├─► CLIパイプ & TCP IPC (127.0.0.1:49152)
       ├─► ローカルLLMエンジン (Ollama / vLLM)
       ├─► デイリースクラップ集約 (scraps/YYYY-MM-DD.md)
       ├─► クラウド推論 (Gemini / Claude)
       ├─► 並列Grepエンジン (runtime.NumCPU())
       ├─► バックグラウンドGit同期
       ├─► ダイレクトファイルIO (UTF-8 / Shift_JIS)
       ├─► ループバックメディアエンジン
       └─► メモリ回収機構 (積極的GC)
```
