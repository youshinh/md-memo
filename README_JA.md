## 私たちが解消する摩擦

現代のナレッジツール（Obsidian、Notion、VS Code）は並外れて優れたデータベースですが、**思考の走り書き（スクラッチパッド）としては重すぎます。**

ふとアイデアが閃いた瞬間や、一時的なバグ調査のログを殴り書きしたいとき：
- **Electronランタイムと大量のプラグインの起動に 2〜5秒 待たされ**、その間にせっかくの閃きが蒸発してしまう。
- **IMEの状態と戦わされる**: 半角英数モードのまま入力して `konnichiha` と誤爆したり、コードブロックを開いた瞬間に全角文字（`ｃｏｎｓｔ　ｘ　＝`）でコードが汚染される。
- **プライバシーを犠牲にする**: 補完機能を使うためだけに、コミット前の思考や機密コードを外部のクラウドAPIへ送信しなければならない。

**MD-Memo は、人間の生物学的な思考とローカルファイルシステムの間に静かに佇むよう設計されています。**  
これは永続保管用の目的地（wiki）ではありません。わずか 10ms（0.01秒）で目覚め、待機メモリをほぼゼロに抑え、思考を書き終えた瞬間に視界から消え去る「超高帯域幅の思考キャプチャ装置」です。

## ワークフローにおける位置づけ

MD-Memo は永久保管庫や既存のナレッジベースと競合しません。**入力の初動摩擦を極限まで削ぎ落とすことで、それらを真に強化します。**

| 次元 | メモ帳 (Notepad) | Electron製保管庫 (Obsidian) | MD-Memo |
|---|---|---|---|
| **起動・復帰** | コールド起動のみ (~0.1s) | 重量級 (2.0s – 5.0s) | **瞬時 (0.01s トレイ / <0.1s コールド)** |
| **待機メモリ** | ~15 MB | 400 MB – 800 MB+ | **5 – 15 MB (アクティブ時 ~40 MB)** |
| **保存形式** | プレーンテキスト | Vault / 独自内部DB | **100% ネイティブPOSIX プレーンテキスト** |
| **ファイルダイアログ** | C++ Win32 | Node.js IPCラッパー | **Windows COM `IFileDialog` / Cocoa直結** |
| **IMEの認知摩擦** | 手動切り替えが必須 | 手動切り替えが必須 | **自律型 4層 Auto-IME Guardian (0 ns)** |
| **インライン補完** | なし | プラグイン依存（クラウド送信） | **ネイティブ ローカルLLM (完全オフライン)** |
| **構文・図解描画** | プレーンテキストのみ | プラグインレイヤー依存 | **Mermaid 11 & Vision OCR 標準内蔵** |
| **自動化・パイプ** | なし | コミュニティ拡張 / シェル起動 | **AI CLIエージェント & Unixパイプ統合** |
| **執筆への没入** | 静的なテキスト欄 | 複雑なマルチペインUI | **ミニマルキャンバス + 視線を導く Cursor Aura** |

> [!TIP]
> **理想的な連携運用**: MD-Memo を常駐させ、作業中の **Obsidian Vault** や **Gitリポジトリのディレクトリ** を保存先として直結。思考の初速を最速でメモし、後からナレッジベース側で整理する運用が最も強力です。

## 超能力 (Superpowers)

### 1. 0.01秒の瞬時復帰 & 待機時 5 MB フットプリント
コンパイル済みGoコア（~3.5 MB）とOS標準のネイティブWebView（WebView2 / WebKit）を直結。Node.jsや内蔵Chromiumの多重ランタイムを完全に排除しました。
- **グローバル召喚 (`Ctrl+Alt+M` / `Option+Cmd+M`)**: タスクトレイからわずか 10ミリ秒（0.01秒）で瞬時に復帰。バッファとカーソル位置を完全維持したまま即座に執筆を再開できます。
- **積極的なアイドルメモリ回収**: 待機時や最小化時はメモリ回収機構（`debug.FreeOSMemory`）が自動稼働し、フットプリントを 5〜15 MB まで自動圧縮。24時間365日常駐させてもリソースを消費しません。
- **OSネイティブダイアログ**: Windows COM `IFileDialog` および macOS Cocoaパネルを直接叩くことで、ミリ秒未満の高速ファイルナビゲーションを提供。

### 2. 世界初の 4層 Auto-IME Guardian
日本語と英数字・コードが頻繁に入り乱れる技術執筆において、入力モード切り替えの認知的摩擦を根絶します。
- **自律的スクリプト反転**: 半角英数モードのままローマ字を打ち始めても、子音・母音の拍動リズムを音韻論的に解析し、わずか3文字以内に自然な日本語入力へと自動変換。
- **構文領域の完全隔離 (Lexical Scope Shield)**: インラインコード（`` `...` ``）、フェンスドコードブロック（```...```）、URL内では、IMEおよび全角文字の変換が 0 ns のオーバーヘッドで即座に遮断されます。`interface`、`component`、`const` などの識別子が全角で汚染されることは構造上あり得ません。
- **即時AIタイポ修正 (`Alt+C` / `Option+C`)**: 打ち間違い、不自然な変換、転置されたカナ漢字をショートカット一発でスマートに修正。
- **マイクロ秒単位の実行性能**: 計算言語学の対数尤度比検定（LLRT）を採用。1打鍵あたりわずか約11µs、メモリ35KBで動作し、入力遅延は物理的にゼロです。

### 3. 静寂のエアギャップ・コパイロット (Ghost Text)
画面を占領するおしゃべりなチャットボットではなく、指先に寄り添う静かな影のようなAI：
- **完全オフライン予測補完**: 薄いグレーのゴーストテキストがインラインでリアルタイム出現。`Tab` で全文受け入れ、`Ctrl+→`（macOSは `Option+→`）で1単語ずつ段階的に受け入れ可能。Ollama、LM Studio、vLLM とローカル接続し、機密情報を一切外部に漏らしません。
- **ワンクリック Gemma 4 自動セットアップ**: 設定画面（`Ctrl+,`）の「Gemma 4 導入」ボタンを押すだけで、Ollamaの導入から Google のエッジ最適化モデル Gemma 4 E2B（約2.3Bパラメータ）の取得、接続設定まで完全自動化。クラウド切り替え時の自動プロセス停止・メモリ解放機能も完備。
- **思考プロセスの自動除去**: DeepSeek-R1 などの推論モデルが吐き出す `<think>...</think>` ブロックをリアルタイムに自動除去し、純粋な思考結果のみを描画。
- **Cursor Aura (視線誘導)**: タイピングを止めて思索に耽る瞬間、キャレットの周囲が淡く柔らかに発光。集中力を乱すことなく、思考の焦点を書きかけの行へと静かに留めます。

### 4. マルチモーダル & 視覚構造の即時抽出
- **スクショからMarkdown表への自動OCR (`Ctrl+V` / `Cmd+V`)**: ドキュメント、表計算、ログのスクリーンショットをペーストするだけで、Gemini Vision が構造を認識し、整然としたGitHub Flavored Markdownテーブルへ瞬時に変換。
- **テキストから図解生成**: 箇条書きの粗いメモを選択するだけで、Mermaid 11 のフローチャート、シーケンス図、タイムラインを即座に生成。ベクター図解へのワンクリック画像化もサポート。
- **ローカルメディア配信**: 内部ストリーミングエンドポイント（`/api/image`）経由で、ローカル画像を滑らかな同期スクロール付きでプレビュー可能。

> [!TIP]
> **Gemini API（無料枠）の1分セットアップ**:
> 画像OCRや画像生成、高速補完に利用できるGemini APIは、Google AI Studioにて**クレジットカード登録不要・完全無料**で即時発行できます。
> 1. [Google AI Studio (API Keys)](https://aistudio.google.com/app/apikey) へアクセスし、Googleアカウントでログイン。
> 2. **「Create API key」** をクリック（設定画面の「APIキーを取得 ↗」ボタンからも直結）。
> 3. 設定画面（`Ctrl+,`）→「画像解析」タブの APIキー欄に貼り付けるだけで全機能が開放されます。

### 5. AI CLIエージェント & Unixパイプ統合
テキストエディタの圧倒的な編集速度と、UnixパイプラインおよびAIによるOS自動化を融合：
- **AI CLIエージェント (`Ctrl+Shift+E` / `Cmd+Shift+E`)**: 「128.0.0.1から10までpingして結果まとめて」「直近24時間に更新されたファイルを一覧表示」といった自然言語の指示から、ローカル/クラウドLLMがOSネイティブのコマンド（PowerShell / bash）を自動生成。バー上で内容を確認・編集し、`Enter` 一発でバックグラウンド実行して実行コマンド・時刻・終了コード・出力をセットで新規タブ（`[CLI] <cmd>.md`）へ自動保存・展開します（エラー時も専用エラータブと即時修正バーで安全に再試行可能）。
  - **ローカル付帯情報の自動注入**: 現在開いているファイルの絶対パス、親ディレクトリ、ファイル名、アプリの作業ディレクトリを作業コンテキストとして自動連携。「このファイルをバックアップ」「このフォルダの画像を一覧」といった曖昧な指示も正確にコマンド化します。
  - **多層防御セキュリティ・バリデーション**: ドライブ初期化（`format C:`）、ルート消去（`rm -rf /`）、フォークボム、レジストリ破壊などの破滅的コマンドを構文解析エンジンが無条件ブロック（`BLOCKED`）。再帰削除やシャットダウンは警告バッジ（`⚠️ WARN`）と確認モーダルで安全に防護します。
- **CLIパイプライン・フィルタ (`Ctrl+Shift+B` / `Cmd+Shift+B`)**: 選択範囲またはメモ全体を外部コマンド（`sort`, `uniq`, `jq`, `tr`, `prettier`, `duckdb`, `sqlite3`, `psql` 等）の標準入力に流し込み、標準出力結果で瞬時にインライン置換。
  - **完全非ブロッキング**: バックグラウンド goroutine 実行により、長時間の処理中もエディタのフリーズは物理的にゼロ。
  - **即時中断**: `Escape` キーで即座に外部プロセスツリー全体を強制終了（Windows `taskkill /T /F` 連動）。
  - **スニペット & 履歴補完**: ネイティブ `<datalist>` による定番コマンド・SQLの自動サジェストと最近の実行履歴の自動学習。

### 6. 流れるような編集と分割キャンバス
- **エディタ左右分割 (`Ctrl+\` / `Cmd+\`)**: 複数メモの並列編集が可能。境界線のドラッグで左右の幅を直感的に調整。
- **横並び同期プレビュー (`Ctrl+Shift+V` / `Cmd+Shift+V`)**: 双方向スクロール同期を備えた独立プレビューペインを展開。
- **ホームポジション行操作**: 手をホームポジションから離さずに行の上下移動、複製、削除、上下空行挿入が完結（`Alt+↑/↓`, `Shift+Alt+↑/↓`, `Ctrl+Shift+K`, `Ctrl+Enter`）。
- **設定の完全な可搬性**: 設定画面（`Ctrl+,`）から全設定をJSONファイルとしてワンクリックでエクスポート・インポート可能。

### 7. ターミナル・デイリースクラップ連携 (Terminal-to-Scrap Hub)
ターミナル作業とエディタの合間を走る超軽量な思考・作業デスク 兼 トラブルシューティングDB：
- **CLI標準入力パイプ (`cat log | md-memo`)**: `cat error.log | md-memo` や `git diff | md-memo` でログをパイプ入力すると、起動中のインスタンスへローカルTCP IPC（0ms体感）で即時転送。未起動時は自動起動して直ちにメモを展開。
- **デイリースクラップ自動集約**: 日付ごとのスクラップ（`scraps/YYYY-MM-DD.md`）へ、タイムスタンプと実行元コマンド付き（`## [HH:mm:ss] <cmd>`）で自動追記。起動中のエディタでもリアルタイムにタブへ反映され、末尾へ自動スクロール。
- **VS Code URI連携（エラー箇所の即時ジャンプ）**: プレビュー内の `path/to/file.ext:123` 形式のエラーパスを自動検出し、クリック一発で VS Code の該当ファイル・該当行へ直接ジャンプ（パイプ時のカレントディレクトリを自動補完）。

### 8. 超高速並列スクラップ検索 (`Ctrl+Shift+F` / `Cmd+Shift+F`)
過去のトラブルシューティング記録やメモを瞬時に再利用：
- **ゼロアロケーション並列走査**: CPUコア数（`runtime.NumCPU()`）に応じたワーカースレッドと `bufio.Scanner` による超高速走査。大量の過去スクラップからミリ秒で目的の行を抽出。
- **インクリメンタル検索 & フラッシュジャンプ**: 150msのデバウンスで入力中に即時インクリメンタル検索。候補をクリックすると該当スクラップを開き、目的の行へスクロールして1.5秒間のイエローフラッシュハイライトで視覚誘導。

### 9. バックグラウンドGit自動同期 (Silent Cloud Sync)
Gitリポジトリをメモの保存先として指定するだけで、クラウド（GitHub / GitLab 等）と完全自動同期：
- **非同期Pull & デバウンスPush**: アプリ起動時に非同期で `git pull --rebase` を実行し、コンフリクトを回避。メモ編集・保存から30秒間のアイドル（デバウンス）を検知して自動で `add .` / `commit` / `push` をバックグラウンド実行。
- **ステータスバー統合**: 同期状態（`🔄 Syncing`, `☁ Synced`, `⚠️ Error`）をステータスバーにアイコン表示し、クリックでいつでも手動の即時同期をトリガー可能。
- **ワンクリック初期化 & 接続診断**: 設定画面（`Ctrl+,` →「スクラップ & Git」）でURLを入力し、「接続テスト」でアクセス・認証の成否を即座に判定。「連携 / 初期化」を押すだけでローカルリポジトリの初期化から初回コミット・プッシュまで全自動で完了します。

> [!TIP]
> **誰もが迷わない GitHub 連携 3ステップガイド**:
> 1. **GitHubで空リポジトリを作成**: [GitHub新規リポジトリ作成](https://github.com/new) を開き、リポジトリ名を入力します（Private推奨）。
>    - ⚠️ **最重要**: **「Add a README file」や「Add .gitignore」のチェックは必ず外してください**（空のまま作成することで、初期同期の衝突を100%防止できます）。
> 2. **URLをコピー**: 作成完了画面に表示されるリポジトリのクローンURL（HTTPSまたはSSH）をコピーします。
> 3. **設定画面でテスト＆連携**: MD-Memoの設定（`Ctrl+,`）→「スクラップ & Git」を開き、URLを貼り付けて **「接続テスト」** → **「連携 / 初期化」** を押すだけで完了です！
>    - ※ Git がインストールされていない場合は、表示される案内リンクから Git をインストールしてください。

## 設計思想 (Core Tenets)

1. **道具は透明でなければならない (The Tool Must Disappear)**: ソフトウェアはそれ自身の存在を誇示してはなりません。装飾、不要なアニメーション、思考を遮る通知を完全に排除し、画面には文字のみが存在する状態を保ちます。
2. **決定論的なデータ主権 (Absolute Data Sovereignty)**: 記述された思考は、常にあなた自身のものです。思考はローカルディスク上のクリーンなUTF-8プレーンテキストとして保持され、50年後でも標準的なPOSIXツールで開くことができます。
3. **速さとは敬意である (Speed is Respect)**: 思考を書き留めるために書き手を3秒待たせる道具は、人間の精神に対する敬意を欠いています。MD-Memoのすべてのアーキテクチャの決定は、思考の流速を守るために下されています。
