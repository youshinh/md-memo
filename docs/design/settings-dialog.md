# 設定画面の見直し（v1.10.5 で実装済み）

パネルの共通雛形（panel-template.md）と同じ寸法・部品・言葉に揃えた。触ったのは `frontend/css/style.css` の `#settings-modal` 以下で、`index.html` の構造と `app.js` の保存処理は変えていない（他のダイアログの見た目も変えていない）。

## 構造

- ヘッダー 48px: タイトル 16px/600、右に「詳細設定を表示」のスイッチと ×（押せる範囲 28px）。
- タブ 40px。左右 24px（本文と同じ軸）。
- 本文: 左右 24px、上 16px、下 24px。分類の間 24px。分類名は 12px/600 の明るいアクセント色 + 罫線で、折りたたみの印は右端。
- 行: スイッチの行は最小 36px。説明は 12px（「?」を押すと開く、いまの動作のまま）。「?」のあるスイッチ行では、「?」がスイッチのすぐ左に付く。
- フィールド: 高さ 32px、角丸 4px、枠 1px。フォーカスは枠が緑になり、2px の淡い輪郭が付く。選択欄の矢印は線で描いた 14px。
- 2列の行: 間隔 16px、同じ幅。
- フッター 56px: 左に Export / Import、右に Save、Cancel（並びは変えていない）。
- ショートカット: 上の説明行と「初期値に戻す」を固定し、一覧だけがスクロールする。行 36px、キーは kbd チップ（幅 88px 以上、高さ 24px、等幅 11px）、未設定は破線、記録中は緑の枠（赤は使わない）。分類名はラベルの色。

## 部品の見分け（パネルと共通）

- ラベル（バッジ・分類名）: 明るいアクセント色の文字だけ。塗りも枠も付けない。
- ボタン: 主は緑の塗り、副は枠線、三次は薄いグレーの塗り。
- チップ（「選択範囲 · 58文字」）: 薄いグレーの丸い地。ボタンとは違い、押せない。
- スイッチ: 押すと切り替わる。値は今までどおりチェックボックスの `checked`。
