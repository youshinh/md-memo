Philosophy

思考とメモ帳、距離のパラドックス

Obsidian や Notion に代表されるナレッジベースは情報の蓄積・構造化には卓越していますが、起動に数秒かかり、思考の熱量を削いでしまいます。
MD-Memo は保管庫（Vault）を置き換えるものではありません。その手前で思考を一瞬も逃さず書き留める「摩擦ゼロの即時メモ帳（スクラッチパッド）」です。

比較項目 一般的なテキストエディタ ナレッジ保管庫 (Notion / Obsidian) MD-Memo
アーキテクチャ C++ / Swift / Rust Electron / Chromium (重厚) Go 1.26 + OS ネイティブ WebView
復帰レイテンシ ~100ms (コールド起動) 2.0s – 5.0s (JS初期化待ち) < 15ms (システムトレイ常駐)
待機メモリ ~15 MB 400 MB – 800 MB+ 5 – 15 MB (積極的 GC 回収)
IME 制御 OS まかせ（全角誤爆頻発） OS まかせ 自律型 IME シールド (全角自動排除)
AI 補完 クラウド依存 (有料/要APIキー) クラウド依存 / 拡張プラグイン ローカル (Ollama) / 任意でCloud AI
データ保存 プレーンテキスト 独自DB / クラウド同期 100% ローカル POSIX プレーンテキスト
Capabilities

技術基盤とディテール

目立たず、待たせず、思考を遮らない。プロダクトの細部に宿るエンジニアリング。

ゼロレイテンシ・常駐復帰

トレイ常駐から Ctrl+Alt+M（Mac: Option+Cmd+M）で瞬時に復元。ウィンドウ最小化時は debug.FreeOSMemory() でワーキングセットを 5〜15MB まで極限まで縮小。

  • Go 1.26
  • OS Native WebView
  • Zero IPC Lag

自律型 IME シールド

インラインコード（`...`）やブロック、URLの内部では全角文字を自動インターセプト。誤って半角モードで入力したローマ字拍動も対数尤度比検定（LLRT）で検知し自動補正。

  • 11µs Overhead
  • LLRT Engine
  • Syntax Guardian

ローカルファースト AI (Ghost Text)

完全オフラインで推論可能なローカル Ollama / vLLM と連携。外部へのデータ流出を防ぎながら、Ctrl+→ で高速予測補完。Vision OCR などの高度推論時はクラウドAIも柔軟に選択可能。

  • Local / Offline
  • Ollama / vLLM
  • Ghost Text

UNIX パイプ & CLI 自動化

ターミナルから cat build.log | md-memo で起動中インスタンスへミリ秒転送。さらに Ctrl+Shift+E で安全な自然言語 OS コマンドエージェントを実行可能。

  • Local TCP IPC
  • Safe CLI Agent
  • Pipe Filter

並列スクラップ検索

runtime.NumCPU() のワーカースレッドとゼロアロケーション並列スキャナにより、過去のデイリースクラップ（scraps/YYYY-MM-DD.md）全体を瞬時に Grep 検索。

  • Parallel Scan
  • 150ms Debounce
  • Auto Highlight

サイレント Git 同期

キー操作停止から 30 秒のアイドル後にバックグラウンドで自動コミット＆プッシュ。アプリ起動時には自動リベース。設定画面で Git リポジトリ URL を指定するだけで完全同期。

  • Auto Pull / Push
  • Conflict-Free
  • Zero Friction

画像キャプチャの即時Markdown化

Gemini Vision OCR 統合

OS標準の矩形選択キャプチャ（Win+Shift+S / Cmd+Shift+4）で画面やUIモックを切り取り、MD-Memo上で Ctrl+V（ペースト）するだけ。専用ソフトやアップロード画面を開くことなく、画像内の情報をマークダウンとして即時バッファ展開します。

1
クリップボードからダイレクト検知 画像ペーストを検知すると、エディタに仮アンカー [画像マークダウン変換中 (Gemini)...] を非同期挿入し、入力をブロックしません。
2
単なるOCRを超えた「構造認識」 文字列のベタ打ちではなく、表構造（Markdown Table | 列 |）、見出し階層、インデント付き箇条書き、Mermaid図解候補を自動判別して構造化。
3
コードスニペットのシンタックス自動付与 画面内のコード画像は、言語（```typescript 等）を推定したフェンスドコードブロックとしてクリーンに展開。手動での打ち直しを根絶します。
# デザイナー＆リサーチャーの実用例:
> UI料金表スクショ ➔ Markdownテーブルへ自動変換
> ホワイトボード写真 ➔ 箇条書きアクションリストへ構造化
  • Clipboard Paste (Ctrl+V)
  • Async Non-blocking
  • Auto Markdown Table
  • Vision Model API

AI CLI を活用した双方向パイプライン

UNIX Pipe & AST セーフティエージェント

エディタを独立した孤島にせず、OSやターミナルとの双方向データパイプラインとして機能させます。自然言語指示からシェルコマンドを自動生成し、AST安全解析で厳格に保護した上で非同期実行します。

組み込み AST & Regex セーフティウォール搭載
A
Inbound: ターミナルからメモへ直結パイプ cat build.log | md-memo や docker logs ... | md-memo。TCP IPC（127.0.0.1:49152）経由でデイリースクラップ（scraps/YYYY-MM-DD.md）へミリ秒転送。
B
In-Editor: 自然言語 AI CLI エージェント (Ctrl+Shift+E) 「ポート8080のプロセスを特定」「更新されたファイルを検索」と指示。LLMが安全なコマンドを推論し、Goroutineで非同期実行＆出力をバッファへ挿入。
C
Outbound: 外部 CLI フィルタ (Ctrl+Shift+B) 選択テキストを jq、prettier、sort などのローカルCLI標準入力に流し込み、整形結果で選択範囲をインプレース置換。
# セーフティエンジンによる危険コマンド自動ブロック例:
! BLOCKED: rm -rf / , format c: , diskpart , :(){ :|:& };:
? WARNING: 再帰削除 (rm -r) やシャットダウン時は事前承認ダイアログを表示
  • Local TCP IPC
  • Destructive Cmd Shield
  • CLI In-place Filter
  • Stream Output

並列 Grep & 全文検索エンジン

Goroutine (NumCPU) マルチコアスキャン

「あの時のメモどこだっけ？」をゼロ秒で解決。Ctrl+Shift+F（Mac: Cmd+Shift+F）で、蓄積された全デイリースクラップ（scraps/YYYY-MM-DD.md）をインメモリ並列走査します。

1
runtime.NumCPU() 並列スキャナ CPUコア数に応じたワーカープールと bufio.Scanner により、大量の過去スクラップをゼロアロケーションで並列スキャン。数千ファイルでも瞬時に完了。
2
前後3行のコンテキスト自動抽出 マッチした行だけでなく前後の文脈（SnippetParts）を動的構築。検索モーダル上で前後の文脈を一目で把握可能。
3
150ms デバウンス & 一発ダイレクトジャンプ 入力と同時にインクリメンタル絞り込み。キーボードの ↓/↑ で選び、Enter を押すと該当スクラップを開いて該当行へスムーズスクロール＆ハイライト。
# Grep 実行例 (日付降順で最新メモを優先表示):
> scraps/2026-09-17.md:42 [行42へジャンプ]
| OAuth token expired at 14:02:11

  • Bufio Streaming
  • Context Snippet (3-line)
  • Instant Line Jump

「ターミナルからエディタへのコピペ作業が完全に消滅。スタックトレースの調査が劇的に速くなりました。」
Knowledge Workers Obsidian / Notion Vault 連携

「入口はMD-Memo、保管庫はObsidian」の二層運用

MD-Memoの保存先を作業中Obsidian Vaultの Daily Notes/ フォルダに直接指定。日中の殴り書きやエラーメモは最速のMD-Memoで行い、夕方にObsidianでリンクネットワークに組み込みます。

「保管庫の堅牢さと、スクラッチパッドの機動性を両立する理想のハイブリッド環境です。」
