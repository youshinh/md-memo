MD-Memo Comprehensive Guide

A zero-latency Markdown scratchpad engineered for instant capture.
From first-time setup to advanced JSON-RPC IPC and autonomous CLI agent orchestration.

01 Getting Started: Core Philosophy

MD-Memo does not seek to replace expansive knowledge vaults like Obsidian or Notion. Instead, it serves as the zero-friction, instant-entry buffer standing directly in front of them.

Fleeting thoughts, terminal logs, and exploratory notes are captured with sub-millisecond feel and persisted as standard POSIX Markdown files, ready to be piped into your long-term vault whenever desired.

Three Core Principles
  1. Zero Save Anxiety: Notes autosave automatically after a 1.5-second idle pause.
  2. Instant Summon: Wake the app from your system tray in milliseconds via Ctrl+Alt+M.
  3. Zero Typo Friction: Autonomous IME Shield prevents accidental full-width characters inside code blocks and URLs.

Installation & Launch

MD-Memo is delivered as a lightweight standalone binary with zero installer overhead.

Windows (winget):

winget install youshinh.md-memo

macOS (Homebrew):

brew install --cask youshinh/tap/md-memo

Standalone binaries are also directly downloadable from our GitHub Releases page.

System Tray & Instant Summon (Ctrl+Alt+M)

Clicking the close button minimizes the application to the system tray while aggressively reclaiming working memory down to 5–15 MB via Go's runtime GC.

  • Windows / Linux: Ctrl + Alt + M
  • macOS: Option + Cmd + M

Pressing the global hotkey summons the editor in front of any active window in less than 15ms, with your cursor exactly where you left off.

Autonomous IME Shield (IME Guardian)

Technical writing in multilingual environments often leads to full-width alphanumeric typos (such as ｃａｔ instead of cat) inside code blocks and commands.

  • Lexical Scope Protection: Forces alphanumeric mode inside inline code (`...`), fenced code blocks, and URLs with only 11 µs overhead.
  • Romaji Auto-Conversion: Detects Romaji cadence typed while in direct input mode and seamlessly converts it into proper kana.

Daily Scraps Model

You don't need to invent filenames. MD-Memo defaults to a daily scratchpad file (scraps/YYYY-MM-DD.md) for rapid journaling and terminal pipe captures.

02 Capabilities Guide

Editor & Split Mode (Ctrl+\)

Press Ctrl + \ (macOS: Cmd + \) or click the split icon in the header to open a synchronized 2-pane view.

Figure 1: Live 2-Pane Editor with Mermaid Preview Ctrl + \

Live Mermaid Diagrams & Image Rendering

Fenced code blocks with ```mermaid render live diagrams in the preview pane. You can right-click any diagram and choose "Render Image..." to generate a high-resolution PNG using Nano Banana 2 Lite.

Inline AI Prompt Bar (Ctrl+K / Ctrl+L)

Select text and trigger Ctrl + K to summon an in-place AI instruction bar without modal popup friction.

Figure 2: Non-modal Inline AI Prompt Bar Ctrl + K

Ghost Text (Predictive Completion)

Powered by your local Ollama instance or cloud API, ghost text appears inline as you pause typing.

  • Accept All: Press Tab
  • Accept Next Word: Press Ctrl + → (macOS: Option + →)
  • Dismiss: Keep typing to silently discard.

Jev Autonomous Actions & AST Safety Guardrail

MD-Memo's "System 1" engine continuously parses markdown tasks (e.g. - [ ] check git status) and suggests safe executable actions in a 3-Beam action bar.

Destructive commands (like rm -rf /) are deterministically intercepted and blocked by the built-in AST Command Verifier.

Paste Image OCR (Ctrl+V)

Paste any clipboard image with Ctrl + V to trigger Gemini Vision OCR, transcribing diagrams, tables, and handwritten notes into structured Markdown.

CLI Pipeline Filter (Ctrl+Shift+B)

Transform text selections directly through standard UNIX tools like jq, sort, tr, or duckdb.

Figure 3: Instant CLI command stream filter Ctrl + Shift + B

Natural Language AI CLI Agent (Ctrl+Shift+E)

Describe system tasks in plain English (*"find files modified in the last 24 hours"*). The agent generates the shell command, validates safety, executes it, and delivers output to a fresh tab.

Parallel Daily Scrap Search (Ctrl+Shift+F)

Leverages all available CPU cores (runtime.NumCPU()) to execute in-memory regex grep scans across your historical scraps in under 150ms.

Figure 4: Multithreaded parallel grep search Ctrl + Shift + F

Command Palette (Ctrl+Shift+P)

Access every editor command, hotkey, and setting via keyboard fuzzy search.

03 Settings Reference

Open settings via the top slider icon or context menu. Settings are organized across 5 distinct tabs.

Figure 5: General Settings Panel Settings → General

1. General Tab

Setting Default Description
Accent Color Theme Dark Olive Choose between Dark Olive, VS Code Blue, Forest Teal, and Charcoal Monochrome.
Language English / Japanese Switch the UI language.
Restore Open Tabs Enabled Restores unsaved buffers and previous tabs upon application launch.
2-Pane Split by Default Disabled Always launches in split view when checked.
Resident in Tray Enabled Minimizes to tray on close, keeping sub-15ms wake ready.
Autosave on 1.5s Pause Enabled Silently saves existing files upon a 1.5-second typing pause.
IME Guardian Enabled Protects code blocks against IME full-width character leakage.

2. AI Models Tab

Figure 6: Local Ollama & Cloud LLM Configuration Settings → AI Models
  • Local AI Setup: 1-click installation and management for Ollama and Gemma 4 E2B.
  • Text LLM: Base URL, model name, and API keys for OpenAI-compatible endpoints or Gemini.
  • Ghost Text: Configurable suggestion delays (ms) and token limits.
  • Vision OCR: Target vision models like Gemini Flash Lite or Qwen 2.5 VL.

3. Agent & CLI Tab

Figure 7: Autonomous Agent Execution & Pipe Limits Settings → Agent
  • agents.yaml: Direct shortcut to customize external agent profiles (Claude Code, Hermes 3, Codex, AGY).
  • Agent Timeout: Maximum execution window for background tasks (default 180s).
  • Ghost Diff Duration: Duration in ms to highlight external modifications.
  • Max Pipe Size: Failsafe buffer limit for stdin terminal pipes (default 10MB).

4. Sync Tab (Git & Scraps)

Figure 8: Daily Scraps Directory & Background Git Sync Settings → Sync
  • Daily Scraps Folder: Path where cat file | md-memo and daily notes reside. Can point directly to an Obsidian vault.
  • Background Git Sync: Runs git pull --rebase on launch and debounces commits/pushes after 30 seconds of idle time.

04 Power User & Hackers Manual

MD-Memo is fully programmable via local TCP IPC (JSON-RPC 2.0) and headless CLI commands.

UNIX Terminal Pipe

Pipe standard output directly into MD-Memo. Transmits to the running instance in <1ms, timestamps the entry in today's scrap, and raises the window. 

cat build.log | md-memo
curl -s https://api.github.com/zen | md-memo

JSON-RPC 2.0 API Specification

Upon startup, MD-Memo writes port and session tokens to session.json. Connect via TCP port 49152:

Method Params Description
buffer.get {"tab_id": "..."} Retrieve content, SHA-256 hash, and generation index.
buffer.set {"content": "...", "expected_hash": "..."} Atomic replace with conflict detection while preserving undo tree.
buffer.append {"content": "..."} Append to the active buffer.
buffer.replace {"start_line": 1, "start_col": 0, "end_line": 2, "end_col": 0, "content": "..."} Selective range replacement.
ui.toggle_split {} Toggle 2-pane split mode.
ui.activate {} Bring window to the foreground.

Headless CLI Commands

# Fetch current buffer
md-memo buffer get --json

# Replace buffer from terminal stream
echo "# Updated note" | md-memo buffer set

# Verify shell command safety against AST Guardrail
md-memo jev verify "rm -rf /"
# Output: {"is_safe": false, "reason": "Destructive command blocked by AST guardrail"}

External Editor Recipes

Neovim / Vim Send Command:

command! MDMemoSend :w !md-memo

PowerShell Clipboard Append:

Get-Clipboard | md-memo buffer append
