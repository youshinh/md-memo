ドキュメント & 設定マニュアル

MD-Memo 活用ガイド

0秒でひらめきを捕まえる軽量スクラッチパッド「MD-Memo」。
はじめて使う方の基本操作から、CLI・自律エージェント・JSON-RPCを駆使する玄人向けのカスタマイズまでを網羅しています。

01 はじめての方へ：MD-Memoの基本思想

MD-Memoは、NotionやObsidianのような巨大なナレッジベースと競合するものではありません。「それらの直前に置く、ゼロ抵抗の一時記憶バッファ」です。

ひらめいたアイデア、エラーログ、作業中の殴り書きを、起動待ち0秒でそのままテキストファイルとして蓄積し、必要に応じてナレッジベースに流し込みます。

安心のための3つの設計
  1. 保存ボタンを押さなくて良い：1.5秒入力が止まるだけで自動保存されます。
  2. アプリを起動し直さなくて良い：常駐トレイから Ctrl+Alt+M でミリ秒復帰します。
  3. コードや英語入力で全角にイライラしない：IME Guardian が自動で全角誤爆を防ぎます。

インストール & 起動

MD-Memoは単一バイナリで動作し、インストーラー不要で即座に使えます。

Windows (winget):

winget install youshinh.md-memo

macOS (Homebrew):

brew install --cask youshinh/tap/md-memo

または Releases ページ から zip をダウンロードして任意のフォルダに展開してください。

トレイ常駐と瞬時召喚 (Ctrl+Alt+M)

右上の閉じるボタン（✕）を押しても、プロセスは終了せずシステムトレイに常駐します（消費メモリはGCによりわずか5〜15MBに圧縮）。

  • Windows / Linux: Ctrl + Alt + M
  • macOS: Option + Cmd + M

このキーを押すと、どのアプリを開いていても最前面に瞬時に現れ、カーソルも直前の位置に即座に復帰します。メモが終わったらもう一度ホットキーを押すか、ウィンドウを閉じればすぐにバックグラウンドへ戻ります。

IME Guardian：コード入力時の全角誤爆の完全排除

日本語IMEをオンにしたままインラインコード（`...`）やコードブロック（```）、URLを入力した際、全角アルファベット（ｃａｔ や ｆｉｎｄ）が混ざって実行エラーになるストレスをゼロにします。

  • レキシカルスコープ保護: コードブロック内では自動的に半角英数モードへと誘導されます（入力遅延わずか11µs）。
  • 直接入力のローマ字自動修復: 半角直接入力モードで「konnitiha」と打ってしまった場合、自動でひらがな変換へ救済します。

デイリースクラップ思想（日報メモ）

ファイル名を考える必要はありません。MD-Memoは自動的に日付ごとのスクラップファイル（scraps/YYYY-MM-DD.md）を作成します。

後述の Ctrl+Shift+F を使えば、過去数年分のデイリースクラップをミリ秒単位で全文検索できます。

02 機能別 操作ガイド

エディタ & スプリット表示 (Ctrl+\)

MD-Memoは高速なモノスペースMarkdownエディタです。ヘッダーの分割アイコンまたは Ctrl + \（macOS: Cmd + \）を押すことで、2ペイン表示に切り替わります。

  • 左右スクロール同期: 片方をスクロールすると、もう片方も追従します。
  • プレビューモード切替: 右ペインのプレビューアイコンで、リアルタイムHTMLレンダリングを表示します。
図1: スプリットビューでの編集とMermaidリアルタイム描画 Ctrl + \

Mermaid 図の自動描画 & 画像生成

```mermaid で記述されたフローチャート、シーケンス図、ガントチャートは、プレビュー画面でリアルタイムに美しい図としてレンダリングされます。

さらに、図の上で右クリックして 「Render Image...」 を選択すると、Gemini（Nano Banana 2 Lite）と連携して高解像度PNG画像としてエクスポートすることも可能です。

インライン AI プロンプトバー (Ctrl+K / Ctrl+L)

エディタ内で文章を選択し、Ctrl + K を押すと、画面上部にインラインプロンプトバーが出現します。

  • 「このエラーメッセージの原因と修正法を教えて」
  • 「日本語に自然に翻訳して」
  • 「箇条書きの議事録に要約して」

Enterキーを押すだけで、元の選択範囲がAIの生成したテキストでインプレース置換または追記されます（Undoで即座に戻せます）。

図2: 思考を中断しないインラインAIプロンプトバー Ctrl + K

ゴーストテキスト（予測入力）

タイピング中に一瞬静止すると、ローカルLLM（Ollama / Gemma 4）またはクラウドAPIが次に続くテキストを薄い文字（ゴーストテキスト）で提案します。

  • 全文採用: Tab キー
  • 1単語だけ採用: Ctrl + →（macOS: Option + →）
  • 無視して続行: そのままキーを押し続ければ、ゴーストテキストは静かに消えます。

Jev 自律アクションエンジン & AST安全性ガードレール

「System 1」型の高速推論エンジンが、メモに書かれたタスクやコマンド（例: - [ ] git status を確認する）を読み取り、安全に実行可能なシェルアクションを3-Beam予測バーとして控えめに提示します。

破壊的コマンド（rm -rf /, mkfs 等）は内蔵の 決定論的ASTガードレール（AST Command Verifier） によって完全にブロックされるため、安全にワンクリック実行できます。

画像貼り付け OCR 文字起こし (Ctrl+V)

スクリーンショットや設計図の画像をクリップボードにコピーした状態で、MD-Memo上で Ctrl + V を押すだけで、Gemini Vision OCR が起動し、画像内のテキスト・表・コードを構造化されたMarkdownとして貼り付けます。

CLI パイプライン・フィルタ (Ctrl+Shift+B)

選択したテキストをローカルのUNIX系コマンドに流し込み、その標準出力で置換します。

図3: jq や sort, duckdb などを瞬時に適用できるCLIフィルタバー Ctrl + Shift + B

プリセット例:

  • jq . : JSONの整形・インデント
  • sort -u : 重複行を排除してアルファベット順に並び替え
  • tr a-z A-Z : 大文字に一括変換
  • duckdb -box : SQLをインライン実行して表形式で出力

自然言語 AI CLI エージェント (Ctrl+Shift+E)

「今日更新されたファイルを探して」「ポート8080を使っているプロセスを終了して」など、やりたいことを日本語で入力すると、AIが適切なシェルコマンドを生成・AST検証の上で実行し、結果を別タブに表示します。

高速並列スクラップ検索 (Ctrl+Shift+F)

Ctrl + Shift + F を押すと、高速検索モーダルが開きます。

CPUの全コア（runtime.NumCPU()）を駆使したマルチスレッド並列Grepにより、過去数万行のデイリースクラップから探したい単語を150ms未満で抽出し、クリックした行へ一瞬でジャンプします。

図4: 過去のスクラップを瞬時に串刺し検索する並列Grepモーダル Ctrl + Shift + F

コマンドパレット (Ctrl+Shift+P)

Ctrl + Shift + P（macOS: Cmd + Shift + P）で、すべての機能、設定、ファイル操作、AI呼び出しをキーボードだけで検索・実行できます。

03 設定リファレンス (Settings Deep Dive)

ヘッダーのスライダーアイコンまたは右クリックメニューから「Settings...」を開くと、5つのタブに分類された詳細設定画面が表示されます。

図5: 一般設定（テーマ・ウィンドウ・エディタ挙動） Settings → 一般

1. 一般タブ (General)

項目 既定値 説明
アクセントカラー配色 (テーマ) ダークオリーブ Dark Olive, VS Code Blue, Forest Teal, Charcoal Monochrome から選択。
表示言語 (Language) 日本語 / English UI全体の表示言語を切り替えます。
前回開いていたタブの復元 有効 (ON) 再起動時に、未保存のバッファや開いていたタブを完璧に復元します。
起動時に分割エディタで表示 無効 (OFF) 常に2ペイン状態で起動したい場合はチェックを入れます。
トレイに常駐 有効 (ON) 閉じるボタンで終了せずトレイに潜み、Ctrl+Alt+M でミリ秒起動します。
1.5秒入力停止時に自動保存 有効 (ON) 既存ファイルを開いて編集した際、タイピング停止から1.5秒で自動保存します。
IME Guardian 有効 (ON) コードブロック内での全角英数誤爆を自動補正します。
停止時のカーソル微光 有効 (ON) タイピングが止まった際、カーソル周辺に穏やかな光のアフォーダンスを表示します。

2. AIモデル タブ (AI Models)

MD-Memoは完全オフラインのローカルLLMから、最新のクラウドAPIまで自由に設定できます。

図6: ローカルOllamaとクラウドAPIの設定 Settings → AIモデル
  • Local AI (Ollama & Gemma 4): 「Install Gemma 4」ボタンを押すだけで、Ollama環境のセットアップと軽量モデルの取得を自動実行します。
  • Text LLM: チャット・インライン編集用のAPI Base URL、モデル名、API Key、System Promptを設定できます（OpenAI互換、Gemini、Claude対応）。
  • Ghost Text (予測補完): 入力遅延（ms）や最大予測トークン数を細かくチューニング可能。
  • Image OCR & Vision: Gemini Flash Lite や Qwen 2.5 VL 等を指定。

3. 連携 タブ (Agent & CLI)

Claude Code、Hermes 3、Codex、Google Antigravity 2.0（AGY）などの外部自律エージェントや、パイプ入力制限を設定します。

図7: 自律エージェント設定・実行ポリシー・パイプ上限 Settings → 連携
  • agents.yaml を開く: 外部ファイル経由でカスタムエージェントのコマンドライン引数やスロットルールを定義できます。
  • エージェントタイムアウト: 長時間動作するエージェントの強制終了秒数（既定: 180秒）。
  • Ghost Diff 発光時間: エージェントがバッファを変更した際、変更行がハイライトされる時間（ms）。
  • 標準入力パイプ最大サイズ: ターミナルから cat log | md-memo で流し込める最大サイズ（既定: 10MB）。巨大ファイルによるメモリ圧迫を防ぎます。

4. 同期 タブ (Sync: Scraps & Git)

図8: 日報スクラップフォルダとGitHubバックグラウンド自動同期 Settings → 同期
  • Daily Scraps Folder Path: スクラップファイルが保存されるディレクトリ。ObsidianのVaultフォルダやDropboxフォルダに直接指定することも可能です。
  • Git 自動同期: 起動時に git pull --rebase を行い、編集後30秒アイドルが続くと自動で git add/commit/push をバックグラウンド実行します。
  • 接続テスト & 初期化: 空のGitHubリポジトリURL（https://github.com/user/scraps.git）を入力して「Link / Init」を押すだけで、自動でローカルgit初期化とリモート紐付けを行います。

04 玄人向けハック & プログラマブル制御

MD-Memoはエンジニアのためのハッカブルなツールです。ローカルTCP IPC（JSON-RPC 2.0）およびCLIサブコマンドにより、あらゆるシェルスクリプトや外部エディタから完全に遠隔操作できます。

UNIX パイプライン連携

ターミナルの出力を直接パイプで流し込むと、ミリ秒で起動中インスタンスの今日のスクラップ（scraps/YYYY-MM-DD.md）末尾にタイムスタンプと実行コマンド名付きで追記され、ウィンドウが自動で前面化します。 

# コマンドの標準出力を即座にメモへ流し込む
cat build.log | md-memo

# curlの結果をメモに直接記録
curl -s https://api.github.com/zen | md-memo

JSON-RPC 2.0 TCP IPC 仕様

MD-Memo起動時、~/.config/md-memo/session.json（Windowsでは %APPDATA%/md-memo/session.json）にアクティブなTCPポート番号（既定: 49152）とセッション情報が記録されます。

任意の言語からローカルTCPソケットを開き、標準的な JSON-RPC 2.0 リクエストを送信可能です。

メソッド パラメータ例 説明
buffer.get {"tab_id": "active"} 現在のバッファ内容、ハッシュ（SHA-256）、世代番号、行数を取得。
buffer.set {"content": "...", "expected_hash": "..."} バッファ全体を置換。楽観的ロック（競合検知）に対応し、Undo履歴を保持。
buffer.append {"content": "\n- [ ] New Task"} 現在のバッファ末尾にテキストを追加。
buffer.replace {"start_line": 1, "start_col": 0, "end_line": 2, "end_col": 0, "content": "..."} 指定した行・列の範囲のみを選択的に置換。
tab.list {} 開いている全タブの一覧とアクティブ状態を取得。
tab.switch {"tab_id": "tab_123"} 指定タブにフォーカスを切り替え。
ui.toggle_split {} スプリットエディタの開閉をトグル。
ui.activate {} ウィンドウを最前面にフォーカス。
ui.eval {"expression": "window.getTheme()"} WebView2内部で任意のJavaScript式を実行して結果を返却。

Headless CLI サブコマンド リファレンス

GUIを起動せずに、単体バイナリとしてのCLIモードで直接コマンドラインからMD-Memoを操作できます。 

# 1. 起動中のMD-Memoからバッファ内容をプレーンテキストで取得
md-memo buffer get

# 2. JSON形式でメタデータ（ハッシュ、文字数、行数）を含めて取得
md-memo buffer get --json

# 3. テキストを流し込んでバッファを置換
echo "# 新しいノート" | md-memo buffer set

# 4. 競合防止（楽観的ロック）付きでバッファを安全に置換
echo "安全な更新" | md-memo buffer set --expected-hash a1b2c3d4

# 5. 特定行のみを置換
echo "置換テキスト" | md-memo buffer replace --start 2:0 --end 2:10

# 6. コマンドの安全性をAST検証エンジンでテスト（Headless）
md-memo jev verify "git status && npm test"
# 出力: {"is_safe": true, "reason": "Deterministic AST check passed"}

# 7. 危険なコマンドの検証テスト
md-memo jev verify "rm -rf /"
# 出力: {"is_safe": false, "reason": "Destructive command blocked by AST guardrail"}

外部ツール・エディタとの連携レシピ

Neovim / Vim から現在のバッファをMD-Memoへ送信:

" .vimrc / init.vim
command! MDMemoSend :w !md-memo

PowerShell からクリップボード内容を追記:

Get-Clipboard | md-memo buffer append

tmux のペイン出力をスクラップへダンプ:

tmux capture-pane -p | md-memo
