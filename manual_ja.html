ドキュメント & 設定マニュアル

MD-Memo 活用ガイド

0秒でひらめきを捕まえる軽量スクラッチパッド「MD-Memo」。
はじめて使う方の基本操作から、CLI・自律エージェント・JSON-RPCを駆使する玄人向けのカスタマイズまでを網羅しています。

01 はじめての方へ：MD-Memoの基本思想

MD-Memoは、NotionやObsidianのような巨大なナレッジベースと競合するものではありません。「それらの直前に置く、ゼロ抵抗の一時記憶バッファ」です。

ひらめいたアイデア、エラーログ、作業中の殴り書きを、起動待ち0秒でそのままテキストファイルとして蓄積し、必要に応じてナレッジベースに流し込みます。

安心のための3つの設計
  1. 保存ボタンを押さなくて良い：1.5秒入力が止まるだけで自動保存されます。
  2. アプリを起動し直さなくて良い：常駐トレイから Ctrl+Alt+M でミリ秒復帰します。
  3. コードや英語入力で全角にイライラしない：IME Guardian が自動で全角誤爆を防ぎます。

AI まわりの機能は 「書く」「実行する」「任せる」 の3つの動詞に整理されていて、それぞれ入口はひとつだけです。どれを使えばよいか迷ったときは、迷ったらこの表 をご覧ください。

インストール & 起動

MD-Memoは単一バイナリで動作し、インストーラー不要で即座に使えます。

動作環境: Windows（x64。Microsoft Edge WebView2 ランタイムが必要で、Windows 11 には標準で含まれています。ランタイムがないと MD-Memo は起動できません）、または macOS 10.15 以降。

Windows (winget):

winget install youshinh.md-memo

macOS (Homebrew):

brew install --cask youshinh/tap/md-memo
macOS初回起動について

配布物はアドホック署名のみでApple公証（notarize）は受けていないため、MD-Memo.app を開こうとするとGatekeeperに一度ブロックされます。Finderでアプリを右クリック（Controlクリック）して「開く」を選んで確認するか、xattr -dr com.apple.quarantine "MD-Memo.app" を一度実行して隔離属性を解除してください。次回リリースからはmacOSビルドがユニバーサルバイナリになり、Apple SiliconとIntel Macの両方に対応します。

Macを持っていない場合でも、このリポジトリへのプッシュのたびにGitHub上のmacOSランナーがすぐ実行できる MD-Memo.app をビルドします。Actions タブを開く（または CI ワークフローを Run workflow で手動実行する）→ 最新の CI 実行を開く → Artifactsから md-memo-macos-<commit-sha> をダウンロードしてください。こちらも同様にアドホック署名されているため、上記と同じ初回起動手順が必要です。

または Releases ページ から zip をダウンロードして任意のフォルダに展開してください。

アップデートの確認: 起動してしばらくすると、MD-Memoは GitHub に新しいリリースがないかを確認します（api.github.com への1回のリクエストのみで、ノートの内容は送信されません）。新しいバージョンがある場合は、ヘルプ（?）ボタンに小さなバッジが表示されます。

トレイ常駐と瞬時召喚 (Ctrl+Alt+M)

Windowsでは、右上の閉じるボタン（✕）を押してもプロセスは終了せずシステムトレイに常駐します（消費メモリはGCによりわずか5〜15MBに圧縮）。macOSにはメニューバーの常駐アイコンがないため、ウィンドウを閉じてもMD-Memoは終了せずDockに残ります（同様にメモリは圧縮されます）。Dockアイコンをクリックするか、ホットキーで呼び出せば元に戻ります。終了するには Cmd+Q を使ってください。

  • Windows: Ctrl + Alt + M
  • macOS: Option + Cmd + M

このキーを押すと、どのアプリを開いていても最前面に瞬時に現れ、カーソルも直前の位置に即座に復帰します。メモが終わったらもう一度ホットキーを押すか、ウィンドウを閉じればすぐにバックグラウンドへ戻ります。

IME Guardian：コード入力時の全角誤爆の完全排除

日本語IMEをオンにしたままインラインコード（`...`）やコードブロック（```）、URLを入力した際、全角アルファベット（ｃａｔ や ｆｉｎｄ）が混ざって実行エラーになるストレスをゼロにします。

  • レキシカルスコープ保護: コードブロック内では自動的に半角英数モードへと誘導されます（入力遅延わずか11µs）。
  • 直接入力のローマ字自動修復: 半角直接入力モードで「konnitiha」と打ってしまった場合、自動でひらがな変換へ救済します。

デイリースクラップ思想（日報メモ）

ファイル名を考える必要はありません。MD-Memoは自動的に日付ごとのスクラップファイル（scraps/YYYY-MM-DD.md）を作成します。

後述の Ctrl+Shift+F を使えば、過去数年分のデイリースクラップをミリ秒単位で全文検索できます。

02 機能別 操作ガイド

MD-Memoの機能は 「書く」「実行する」「任せる」 の3つの動詞で整理されています。それぞれ覚えるべき入口はひとつだけで、迷ったときのために「アクション候補」という提案機能が別に用意されています。

迷ったらこの表

やりたいこと 入口 どんな機能か
書く
選択した文を直したい・書いてほしい		 Ctrl + K
（macOS: Cmd + K）		 内蔵のLLMが数秒で文章を書き換え・生成します。結果はその場のカーソル位置に返ります。
実行する
コマンドを走らせたい		 コマンドバー
Ctrl + Shift + B / Ctrl + Shift + E		 選択したテキストをシェルコマンドに通し、その出力で置き換えます。待ち時間はコマンド次第で、ほぼ即座です。
任せる
調査や実装をまるごと頼みたい		 ノートに {{ 指示 }} と書く 外部のエージェントCLI（Claude Code、Codex、Hermes、Antigravity など）がバックグラウンドで数分かけて作業します。
何をすべきか分からない Ctrl + J
（macOS: Cmd + J）		 いま書いている内容に合う次の一手を最大3件提案します（アクション候補）。各カードは「書く」「実行」「任せる」のいずれかに対応します。
3つの動詞の見分け方
  • 書くは「いま目の前にある文章」が対象です。選択してから Ctrl + K。
  • 実行するは「コマンドの結果が欲しい」ときです。AIを待つ必要はありません。
  • 任せるは「自分では手を動かしたくない調べ物・実装」です。数分かかることがありますが、その間もノートの編集を続けられます。

書く｜インライン AI プロンプトバー (Ctrl+K / Ctrl+L)

エディタ内で文章を選択し、Ctrl + K を押すと、画面上部にインラインプロンプトバーが出現します。

  • 「このエラーメッセージの原因と修正法を教えて」
  • 「日本語に自然に翻訳して」
  • 「箇条書きの議事録に要約して」

Enterキーを押すだけで、元の選択範囲がAIの生成したテキストでインプレース置換または追記されます（Undoで即座に戻せます）。じっくり指示を書きたいときは Ctrl + L でモーダル版のプロンプト画面を開けます。

図2: 同じプロンプトをダイアログで開いたところ Ctrl + L

よく使う指示はコマンドパレットに用意されています。 Ctrl + Shift + P から次のプリセットを選ぶと、プロンプトバーに定型の指示が入った状態で開きます。

  • UNIX Pipe: 文章推敲・リファクタ — 選択範囲を簡潔で論理的な文章に整えます。
  • UNIX Pipe: 箇条書き要約 — 要点を構造化されたMarkdownの箇条書きにまとめます。
  • UNIX Pipe: 未完了タスク抽出 — 文章からTODOを拾い出し - [ ] 形式のチェックリストにします。

書く｜ゴーストテキスト（予測入力）

「書く」の受け身版です。タイピング中に一瞬静止すると、ローカルLLM（Ollama / Gemma 4）またはクラウドAPIが次に続くテキストを薄い文字（ゴーストテキスト）で提案します。こちらから呼び出す必要はありません。

  • 全文採用: Tab キー
  • 1単語だけ採用: Ctrl + →（macOS: Option + →）
  • 無視して続行: そのままキーを押し続ければ、ゴーストテキストは静かに消えます。

書く｜AI 文章校正・誤字脱字修正 (Alt+C)

指示を書くのも面倒なときは、文章を選択して Alt + C（macOS: Cmd + Shift + C）を押してください。プロンプトを入力せずに、誤字脱字や言い回しの修正だけを行います。内容を書き換えるのではなく整えるための機能なので、議事録や報告文の仕上げに向いています。

書く｜画像貼り付け OCR 文字起こし (Ctrl+V)

スクリーンショットや設計図の画像をクリップボードにコピーした状態で、MD-Memo上で Ctrl + V を押すだけで、Gemini Vision OCR が起動し、画像内のテキスト・表・コードを構造化されたMarkdownとして貼り付けます。

実行する｜コマンドバー: CLI モード (Ctrl+Shift+B)

選択したテキストをローカルのUNIX系コマンドに流し込み、その標準出力で置換します。

ひとつのバー、2つのモード

Ctrl + Shift + B と Ctrl + Shift + E は、同じコマンドバーを違うモードで開いているだけです。バー左端のバッジ（CLI / AI CLI）をクリックすれば、いつでもモードを切り替えられます。コマンドを自分で書けるなら CLI モード、書き方が分からないなら AI CLI モード、と覚えてください。

図3: jq や sort, duckdb などを瞬時に適用できるコマンドバー Ctrl + Shift + B

プリセット例:

  • jq . : JSONの整形・インデント
  • sort -u : 重複行を排除してアルファベット順に並び替え
  • tr a-z A-Z : 大文字に一括変換
  • duckdb -box : SQLをインライン実行して表形式で出力

入力欄にはよく使うコマンドの候補が並びます。実行結果を元のテキストと置き換えず新しいタブで開きたい場合は、設定 → 連携の「コマンド（実行する）」で切り替えられます。

実行する｜コマンドバー: AI CLI モード (Ctrl+Shift+E)

同じコマンドバーの AI モードです。「今日更新されたファイルを探して」「ポート8080を使っているプロセスを終了して」など、やりたいことを日本語のまま入力すると、AIが対応するシェルコマンドを生成します。

生成されたコマンドは実行前に安全性チェックを通ります。システムを破壊しうるコマンドは実行が拒否され、注意が必要なコマンドには警告が表示されます。内容を確認してから実行してください。

任せる｜エージェントに任せる ({{ }})

ノートの本文に {{ 指示 }} と書いて Ctrl + Enter を押す（またはブロックの横に現れる ▶ 実行 ボタンをクリックする）と、その指示が外部のエージェントCLIに渡され、バックグラウンドで実行されます。完了すると {{ }} ごと結果のテキストに置き換わります。この記法を スロット と呼びます。

「書く」との違いは時間の長さです。インラインAIが数秒で返すのに対し、エージェントは数分かけてWeb調査やファイル操作を行います。その間もノートの編集は続けられます。

まずは {{ }} だけ覚えてください

記法は他にもありますが、すべて {{ }} の派生です。迷ったら {{ }} に日本語で書けば動きます。

使い方の手順

  1. ノートに {{ と入力します。カーソルの真下にクイックセレクターが開き、使える記法の一覧が表示されます。
  2. ↑ ↓ で選び、Tab または Enter で確定します。1〜9 の数字キーを押せば一発で確定できます。Esc で閉じます（そのまま文章を打ち続けても自動的に消えます）。
  3. 確定すると {{ code: … }} が挿入され、カーソルは指示を書く位置に入ります。
  4. 指示を書いたら Ctrl + Enter（macOS: Cmd + Enter）で実行します。小さな ▶ 実行 ボタンをクリックしても実行できます。カーソルが、まだ実行していない完結したブロックの中にあると、そのブロックの横にボタンが現れます（ホバー時の表示: 「このスロットを実行 (Ctrl+Enter)」。macOS では Cmd+Enter）。
{{ code: このプロジェクトの設定ファイルを読み込むGo関数を書いて }}

[? 2025年のGoのリリースサイクルと最新の安定版は？ ]

カーソルの位置に実行できるスロットがない場合、Ctrl + Enter を押してもノートの内容は変わらず、ステータスバーに「実行できるスロットが見つかりません（カーソルを {{ }} などのブロック内に置いてください）」と数秒間表示されます。そのスロットがすでに実行中のときは、代わりに「このスロットはすでに実行中です」と表示されます。

日本語入力のまま ｛｛ や 【？ と打ってしまっても、自動的に半角の記号へ直されます。また、コードブロック・インラインコード・Markdownリンク・URLの中に書かれた記号はスロットとして扱われないため、コード例の中に {{ }} が出てきても誤って実行されることはありません。

既定の記法一覧

記法 プロファイル名 既定のエージェント 用途
{{ ... }} code claude-code コード生成。前置きを省き、そのまま動くコードブロックだけを返します。
[? ... ] research claude-code 調査。Web検索を行い、数値と一次ソースURLを添えて簡潔に回答します。
【? ... 】 writing hermes 文章整形。外部通信をせずローカルだけで、読みやすい日本語の箇条書きに整えます。
[! ... !] adversarial claude-code 批判的レビュー。リスク・脆弱性・ボトルネックを3点指摘します。
[>> ... ] deep-research-and-code（レシピ） 既定エージェント 多段実行。調査 → リスク反証 → 実装コード生成を順番に進めます。

記法ごとに呼び出すエージェントと前提の指示（システム指示）が決まっているので、同じ文章を書いても返ってくる形が変わります。どの記法も {{ research: 調べたいこと }} のように先頭へ役割名を書けます。この名前はタスクパネルに表示されるラベルとして使われます。

プロジェクト内に skills/<名前>/SKILL.md を置いている場合は、{{ @skill-name: 指示 }} と書くことで、そのファイルの内容を追加の指示としてエージェントへ渡せます。見つからない場合はスロットがエラー表示に置き換わります。

実行中の様子とタスクパネル (Alt+T)

実行を開始すると、スロットはその場で {{ ⟳ 実行中... }} に置き換わります。エージェントはバックグラウンドで動くので、ノートの他の場所を編集したり、別のスロットを同時に走らせたりできます。

  • タスクパネル: Alt + T（macOS: Option + T）または画面下のステータスバーの「実行中」表示をクリックすると開きます。実行中のタスクと直近の履歴が一覧できます。
  • 途中経過（Hover Peek）: 各タスクカードには、エージェントが出力した最新の1行が1秒ごとに更新されて表示されます。止まっているのか進んでいるのかがひと目で分かります。
  • 中断: タスクカードの「中断」ボタンでプロセスを終了できます。スロットは元の指示文に戻ります。
  • タイムアウト: 既定は180秒です。超えるとスロットにタイムアウトのメッセージが入ります。設定 → 連携の「エージェント（任せる）」で10〜600秒の間で変更できます。

結果の差し込みは、あなたが約0.5秒タイピングを止めるまで待ってから行われます。入力中に横から書き換えられてカーソルが飛ぶことはありません。

結果の受け取りと取り消し

  • Ghost Diff: 結果が差し込まれた直後、エディタが一時的に琥珀色に光り、結果が差し込まれたことが分かります（既定4000ms、設定で変更可）。光るのはエディタ全体で、変更された文字そのものに印が付くわけではありません。
  • 取り消し: 光っている間（および消えてからの1秒間）に Esc を押すと、そのスロットだけが元の指示文に戻ります。Ctrl + Z でも同じように直前のスロット実行を取り消せます。
  • 1行に収める: 文章の途中に埋め込んだスロット（同じ行に他の文字がある場合）は、結果の改行が取り除かれて1行に収まります。

承認ゲート（レシピの途中確認）

[>> ... ] のようなレシピは複数のステップを順番に実行します。危険な操作の手前で人間の確認を挟みたい場合、レシピに requires_approval_step を設定しておくと、そのステップの後で実行が一時停止し、ノートに次のような行が挿入されます。 

- [ ] 次のステップ（実装コードを生成する）を実行する // approve

内容を確認したうえで [ ] を [x] に書き換え、Ctrl + Enter を押すと続きが実行されます。チェックを入れなければ、そこで止まったままです。

エージェントCLIは別途インストールが必要です

MD-Memoはエージェント本体を同梱していません。claude、codex、ollama、agy などのコマンドを事前にインストールし、パスが通った状態にしておいてください。

注意: 組み込みの agy エージェントは確認なしで動作します

組み込みの agy（Antigravity）エージェントは --dangerously-skip-permissions を付けて起動されるため、スロットから実行すると、ファイルの編集やコマンドの実行を確認なしで行います。選択中のエージェントがこのように設定されている場合は、設定 → 連携に警告が表示されます。確認を挟みたい場合は、agents.yaml（後述）で agy を上書きし、args からこのフラグを外してください。

コマンドが見つからない場合、スロットは次のようなエラー表示に置き換わります。原因を直したあと、同じスロットにカーソルを置いて Ctrl + Enter を押せば再実行できます。 

{{ ⚠ エラー: エージェント起動失敗: ... (再試行: Ctrl+Enter) }}

エージェントは、ノートのある場所から上へたどって見つかったプロジェクトルート（.md-memo/、agents.yaml（agents.yml / agents.json でも可）、AGENTS.md、skills/、.git/ のいずれかがあるフォルダ。どれも見つからなければノートのあるフォルダ）を作業ディレクトリとして起動します。プロジェクトルートに .env があれば、その内容が環境変数として渡されます（読み込まれるのはこのファイルだけです）。

agents.yaml で自分好みにする

記法もエージェントも、すべて agents.yaml で変更・追加できます。設定 → 連携の「エージェント（任せる）」にある 「agents.yaml を開く」 ボタンを押すと、ファイルがなければコメント付きの雛形が自動生成されて開きます。

読み込まれる場所は、上から順に最初に見つかったものです（.yaml / .yml / .md / .json のいずれでも構いません）。

  1. <スクラップフォルダ>/.md-memo/agents.yaml（プロジェクトごとの設定）
  2. %APPDATA%\md-memo\agents.yaml（macOS: ~/Library/Application Support/md-memo/agents.yaml）
version: 2
default_agent: claude-code
timeout_seconds: 180
hover_peek_enabled: true
ghost_diff_duration_ms: 4000

# 1. 呼び出すCLIの定義。{instruction} は指示文、{file} はノートの絶対パスに置き換わります。
agents:
  claude-code:
    command: "claude"
    args: ["--file", "{file}", "--prompt", "{instruction}"]
    description: "Claude Code"
  my-agent:
    command: "my-cli"
    args: ["--prompt", "{instruction}"]
    description: "社内用エージェント"

# 2. 記法とエージェントの対応。ここに書いた分だけが有効になります。
slot_profiles:
  - trigger_open: "{{"
    trigger_close: "}}"
    name: "code"
    agent: "claude-code"
    system_instruction: "前置きを省き、そのまま動くコードブロックのみを出力してください。"

  - trigger_open: "<<"
    trigger_close: ">>"
    name: "review"
    agent: "my-agent"
    system_instruction: "変更点をレビューし、指摘を箇条書きで返してください。"

# 3. 複数ステップをまとめて実行するレシピ。
recipes:
  - trigger_open: "[>>"
    trigger_close: "]"
    name: "deep-research-and-code"
    description: "調査 → リスク反証 → 実装"
    steps:
      - "最新の公式仕様とベストプラクティスを調査する"
      - "移行リスクと破壊的変更を指摘する"
      - "上記を踏まえて実装コードを生成する"
    requires_approval_step: 2
    self_refine: true
  • プレースホルダ: {instruction} はスロットに書いた指示、{file} は現在のノートの絶対パスに置き換わります。{instruction} をどこにも書かなかった場合は、最後の引数として自動的に追加されます。
  • 記号の選び方: trigger_open / trigger_close には、Markdownの通常の記法（#、*、- など）とぶつからない組み合わせを選んでください。
  • 上書きの挙動: slot_profiles や recipes を書くと、既定の記法は置き換わります。既定の4種類も残したい場合は、必要なものを書き写してください。一方 agents は、書かなかった既定のエージェント定義がそのまま残ります。
  • self_refine: true にすると、レシピの最初のステップで「下書き → 自己批判 → 修正」を最大2回繰り返してから次へ進みます。
  • ファイルは UTF-8（BOMなし）で保存してください。

提案｜アクション候補 (Ctrl+J)

「何をすればいいか分からない」ときのための機能です。Ctrl + J（macOS: Cmd + J）を押すと、いま書いている内容を読み取って次の一手を最大3件カードで提案します。

カードは、それぞれ性質の異なる候補になるよう選ばれます。内蔵のローカル規則（既定）では、任せるカード（{{ … }} や [? … ] のスロットを挿入してエージェントへ渡す）と実行カード（git status のようなシェルコマンドを走らせる）が出て、並びは「任せる／実行／任せる」になることが多くなります。書くカード（AIに文章を作らせる）は、外部の推論モデルを設定したときだけ出ます。選ぶだけで、その動詞の入口へそのままつながります。

操作 キー
候補を直接選んで実行 Ctrl + 1 〜 Ctrl + 3
（macOS: Cmd + 1 〜 Cmd + 3。Alt+1 〜 Alt+3 でも可）
選択カードを移動 Ctrl + Tab
（Ctrl + Shift + Tab で逆方向。macOS でも Ctrl キーです）
選択中のカードを実行 Enter（Ctrl + Tab で選択を動かしたあと）
閉じる Esc

パネルが開いている間は、ヒント行「Ctrl+1..3 即実行 / Ctrl+Tab 移動 → Enter 決定 / Esc 閉じる」が表示されます。Ctrl + Tab で選択を動かさないまま Enter を押した場合は、ただの改行になります（候補は実行されず、パネルは閉じます）。数字キーだけ・Tab だけ・Ctrl + Enter（これまでどおりスロットの実行に使われます）はパネルに横取りされないので、書くことの邪魔にはなりません。

Ctrl + J で呼び出すほか、入力が一定時間止まったときに自動で提示することもできます（既定で有効）。自動提示が気になる場合は、設定 → 連携の「提案（アクション候補）」で「手動呼び出しのみ」を選んでください。待機時間の長さもそこで調整できます。ショートカットキー自体は 設定 → ショートカット から自由に変更できます。

ステータスバーのバッジ: ステータスバーの「アクション」バッジが現在のモードを表し、クリックするたびに ON → 手動 → OFF → ON と切り替わります。表示は「アクション: ON」「アクション: Ctrl+J」（設定したキー。macOS では Cmd+J）「アクション: OFF」のいずれかです。設定 → 連携 → 提案（アクション候補）の2つのチェックボックスと連動しており、OFF の間は Ctrl + J を押しても何も起こりません。

シェルコマンドを実行する候補は、実行前に必ず安全性チェックを通ります。 rm や dd、mkfs といった破壊的コマンド、システム重要ディレクトリへの書き込み、フォーク爆弾などを検出した場合、その候補は実行されずに理由が表示されます。ただし既知の危険パターンを対象とした防御ですので、最終的な確認はご自身で行ってください。

既定では内蔵のローカル規則だけで候補を出し、ノートの内容は外部に送信されません。送信されるのは、API キーを入力した場合（OpenRouter の固定エンドポイントへ送られます）、または Base URL を OpenRouter の既定値以外に変更した場合（<Base URL>/predict へ送られます）だけで、そのとき外部の推論モデル（Jev など）に問い合わせます。送られるのはキャレット周辺の抜粋で、キャレットの前が最大1,500文字、後ろが最大500文字（合計約2,000文字）です。Base URL とモデル名の欄には https://openrouter.ai/api/v1 と jev-latest があらかじめ入力されていますが、API キーが空のままなら外部には送られません。安全性チェック: AST ガードレール。内部名称の意味は 用語集 にまとめています。

3. 連携 タブ (Agent & CLI)

このタブは、3つの動詞に合わせて「コマンド（実行する）」「エージェント（任せる）」「提案（アクション候補）」の3つのセクションに分かれています。

図7: コマンド（実行する）とエージェント（任せる）の設定。提案（アクション候補）はこの下に続きます Settings → 連携

コマンド（実行する） — コマンドバーの設定です。

  • CLIコマンド生成モデル: AI CLI モード（Ctrl+Shift+E）でコマンドを書かせるモデル名。空欄ならAIモデルタブの設定を引き継ぎます。
  • 実行結果を新しいタブで開く: オンにすると、コマンドの出力で選択範囲を置き換えず、別タブに表示します。
  • 標準入力パイプ最大サイズ: ターミナルから cat log | md-memo で流し込める最大サイズ（既定: 10MB）。巨大ファイルによるメモリ圧迫を防ぎます。

エージェント（任せる） — スロットから呼び出すエージェントの設定です。

  • agents.yaml を開く: 記法・エージェント・レシピを定義する設定ファイルを開きます。まだ無ければコメント付きの雛形を生成します。
  • エージェント: 記法で指定がない場合に使う既定のエージェント。一覧は読み込まれた agents.yaml の内容から作られます。
  • エージェントタイムアウト: 実行を打ち切るまでの秒数（既定: 180秒、10〜600秒）。
  • Ghost Diff 発光時間: 結果が差し込まれた直後にハイライトされる時間（既定: 4000ms）。この間は Esc で取り消せます。
  • ホバー覗き見 (Hover Peek): タスクパネルでエージェントの最新出力行を表示します。

提案（アクション候補） — アクション候補（Ctrl+J）の設定です。

  • メモ入力時に自動提示する: 入力が止まったときに候補を出すかどうか。
  • 手動呼び出しのみ: 自動提示をやめ、Ctrl+J を押したときだけ出すようにします。
  • 入力停止から自動提示までの待機時間（秒）: 自動提示までの間合いを調整します。
  • API Base URL / モデル名 / API Key: 候補を推論するモデルの接続先。API Key を空のままにし、Base URL を既定値（https://openrouter.ai/api/v1、モデル名は jev-latest）のままにしておくと内蔵のローカル推論を使い、キーを入力するか URL を変更するまで何も送信されません。

04 玄人向けハック & プログラマブル制御

MD-Memoはエンジニアのためのハッカブルなツールです。ローカルTCP IPC（JSON-RPC 2.0）およびCLIサブコマンドにより、あらゆるシェルスクリプトや外部エディタから完全に遠隔操作できます。

UNIX パイプライン連携

ターミナルの出力を直接パイプで流し込むと、ミリ秒で起動中インスタンスの今日のスクラップ（scraps/YYYY-MM-DD.md）末尾にタイムスタンプと実行コマンド名付きで追記され、ウィンドウが自動で前面化します。 

# コマンドの標準出力を即座にメモへ流し込む
cat build.log | md-memo

# curlの結果をメモに直接記録
curl -s https://api.github.com/zen | md-memo

JSON-RPC 2.0 TCP IPC 仕様

MD-Memo起動時、接続情報が ipc-session.json に書き込まれます（Windows: %AppData%\md-memo\、macOS: ~/Library/Application Support/md-memo/）。中身は {pid, port, token, started_at} です。ポートは 49152 が優先されますが、使用中の場合は空いているランダムなポートが使われるため、ポート番号は必ずこのファイルから読み取ってください。

任意の言語から 127.0.0.1 のTCPソケットを開き、改行区切りの JSON-RPC 2.0 リクエストを送信できます。

メソッド パラメータ例 説明
buffer.get {"tab_id": "..."} バッファの内容、ハッシュ（SHA-256 の先頭16桁の16進数）、世代番号、行数を取得。tab_id を省略するとアクティブなタブが対象です。バッファ系メソッドのうち tab_id を受け付けるのは buffer.get だけで、ほかはアクティブなタブに対して動作します。
buffer.set {"content": "...", "expected_hash": "..."} バッファ全体を置換。楽観的ロック（競合検知）に対応し、Undo履歴を保持。
buffer.append {"content": "\n- [ ] New Task"} 現在のバッファ末尾にテキストを追加。
buffer.replace {"start_line": 1, "start_col": 1, "end_line": 2, "end_col": 1, "content": "..."} 指定した行・列の範囲のみを選択的に置換。
tab.list {} 開いている全タブの一覧とアクティブ状態を取得。
tab.switch {"tab_id": "tab_123"} 指定タブにフォーカスを切り替え。
ui.toggle_split {} スプリットエディタの開閉をトグル。
ui.activate {} ウィンドウを最前面にフォーカス。
ui.eval {"expression": "document.title"} アプリ内部のWebViewで任意のJavaScript式を実行して結果を返却。
注意: ローカルからのアクセスは認証されません

セッションファイル内の token は任意です。リクエストにトークン（auth フィールド）を付けたうえでそれが間違っている場合にだけ拒否されます。サーバーは 127.0.0.1 でのみ待ち受けますが、同じPC上で動く任意のプログラムがこれらのメソッドを呼び出せます。アプリ内でJavaScriptを実行する ui.eval も例外ではありません。このポートは、ローカルのすべてのプログラムに開かれているものとして扱ってください。

Headless CLI サブコマンド リファレンス

コマンドラインからMD-Memoを操作できます。buffer、tab（list、switch <id>）、ui（activate、toggle-split、eval <expr>）は起動中のMD-Memoが必要で、jev と agent は単体で動作します。出力をリダイレクトまたはパイプした場合は、--text を付けない限りJSONになります。プレーンテキストで保存するには md-memo buffer get --text > note.md のようにしてください。 

# 1. 現在のバッファを表示（ターミナルではプレーンテキスト、リダイレクト時はJSON）
md-memo buffer get

# 2. メタデータ（ハッシュ、世代番号、文字数、行数など）付きのJSONで取得
md-memo buffer get --json

# 3. ターミナルのストリームでバッファを置換
echo "# 新しいノート" | md-memo buffer set

# 4. 読み取り後に変更されていない場合だけ置換（楽観的ロック）
echo "安全な更新" | md-memo buffer set --expected-hash a1b2c3d4e5f60718

# 5. バッファの末尾に追記
echo "- [ ] 新しいタスク" | md-memo buffer append

# 6. 特定の範囲だけを置換（行:桁、どちらも1始まり）
echo "置換テキスト" | md-memo buffer replace --start 2:1 --end 2:10

# 7. コマンドをASTガードレールで検証（終了コード0 = 安全）
md-memo jev verify "git status && npm test"
# [SAFE] Command passed AST validation: git status && npm test

# 8. ブロックされたコマンドは終了コード1で終了。--json なら判定をJSONで出力
md-memo jev verify --json "rm -rf /"
# {
#   "isSafe": false,
#   "reason": "破壊的コマンド \"rm\" は安全基準により実行を拒否されました (Destructive command blocked)",
#   "command": "rm -rf /",
#   "rule": "destructive",
#   "subject": "rm"
# }

# 9. Markdownファイルを、クエリに関係する部分だけに絞り込む
md-memo agent prune --query "ログインのバグ" --file notes.md

外部ツール・エディタとの連携レシピ

Neovim / Vim から現在のバッファをMD-Memoへ送信:

" .vimrc / init.vim
command! MDMemoSend :w !md-memo

PowerShell からクリップボード内容を追記:

Get-Clipboard | md-memo buffer append

tmux のペイン出力をスクラップへダンプ:

tmux capture-pane -p | md-memo

用語集（内部名称と機能の対応）

リリースノートや設定ファイル、CLIのサブコマンドには、開発上の内部名称がそのまま残っています。普段の操作でこれらを覚える必要はありませんが、見かけたときのために意味をまとめておきます。

用語 どの機能のことか 意味
Jev アクション候補 TypeSafe AI が提供する外部の判定・推論モデルの名前です（md-memo に内蔵されているものではありません）。設定 → 連携 → 提案（アクション候補）で API キーを入力するか、Base URL を OpenRouter の既定値以外にしたときだけ使われ、それ以外は内蔵のローカル規則で動作します。md-memo jev verify のように CLI のサブコマンド名としても使われていますが、jev verify（AST 検証）は完全にローカルで動きます。
Slot（スロット） エージェントに任せる ノート本文の {{ }} などの記法そのもの、およびそこからエージェントを呼び出す仕組みのことです。設定ファイル内の slot_profiles はこの記法の定義です。
System 1 アクション候補 「考え込まずに即座に出す」高速推論モードを指す呼び名です。人間の直感的な思考になぞらえた命名で、候補の提示が待たされない理由でもあります。
3-Beam アクション候補 候補を1つに絞らず、同時に3つまで提示する方式のことです。画面に出る3枚のカードがこれにあたります。
MAP-Elites アクション候補 3枚のカードが似たもの同士にならないよう、性質の異なる候補を選び分けるアルゴリズムです（たとえば「実行」カードと「任せる」カードが並びます）。どの種類が出るかは、書いている内容や、外部モデルを設定しているかどうかで変わります。
AST ガードレール アクション候補 / md-memo jev verify シェルコマンドを実行する前に構文として解析し、破壊的コマンドやシステム領域への書き込みなどを検出したら実行を拒否する仕組みです。既知の危険パターンを対象とした防御であり、すべての危険を検知できるわけではありません。
Ghost Diff エージェントに任せる エージェントの結果が差し込まれた直後に、エディタを一定時間琥珀色に光らせて、結果が差し込まれたことを知らせる表示のことです。変更された文字そのものに印が付くわけではありません。光っている間と、その後の1秒間は Esc で取り消せます。
Hover Peek タスクパネル 実行中のエージェントが出力した最新の1行を覗き見る表示のことです。
